# 07 – Market Research: Similar Platforms

Research date: November 2026. Findings are paraphrased from public pages (sources at the bottom). Use this to justify decisions, not to copy products.

## Platforms studied
| Platform | Type | What it does well | Idea to adopt |
|---|---|---|---|
| **Khan Academy Kids** | Free early-learning app, ages 2–8 | 100% free, no ads, no in-app purchases. Thousands of games, books, lessons. Teachers create a class with a **class code**, assign activities, track progress. Parents get a **separate progress view** and can add **multiple children**. Adaptive **learning path**. Core features work **offline**. Free printables. Teachers search the library by subject, level and standard | Free and ad-free as a trust signal. Separate parent view. Library search and filters. Printables. Offline mode |
| **Seesaw** | Student portfolio + family app | Students show work with voice, video, drawing and photos. Parents see only their own child's work and can optionally like/comment. **QR-code login** handouts for classes and printable parent invites. Visual updates work across language barriers | QR/picture login for young kids. Printable parent invites. Portfolio as a later feature. Parent encouragement comments |
| **ClassDojo** | Behavior + parent communication | Points system, messaging, calendar, simple portfolio | Stars/points rewards. Calendar of due dates. Keep messaging optional (Could have) |
| **Google Classroom** | Class management | Assignments, grades, parent summaries | Clear assign → submit → grade lifecycle (already planned) |
| **Outschool / tutoring marketplaces** | Live paid classes | Huge choice, live teachers | Not our model (we are free, admin-curated, not live). Confirms scope: skip live classes and payments |
| **Prodigy and game-style apps** | Gamified practice | Games keep kids engaged more than plain video lectures | Quizzes should feel like play, not tests. Add simple games later |

## What the best platforms have in common
1. Teacher assigns, child does, parent watches. Three distinct views (matches our roles).
2. Kids can start without typing: class codes, QR codes, pictures.
3. Parents get a simple, read-only progress view, not the teacher's dashboard.
4. No ads, no selling data (strong trust message for parents).
5. Content is searchable by subject and level.
6. Offline or low-bandwidth use for real-world homes.
7. Friendly characters, audio, and big touch targets for pre-readers.

## Gaps and opportunity for Little Learner
- Most free apps are English-first. Few serve **Khmer + Arabic + English** with proper RTL. This is a clear differentiator.
- Admin-curated content in three languages is rare in free products.
- Few platforms let the owner edit the whole website from a dashboard. Ours does.
